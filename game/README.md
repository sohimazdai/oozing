# Первая сцена: прогулка по Кроме

Играбельный прототип на **Godot 4.7**. Ночной уборщик стоит у «Пасти динозавра» — минигольфа, перенесённого в Крому вместе с ним. Вокруг — бесконечная местность с холмами, столовыми горами, реками и бродами. Рядом стоит дом с магазином, срезанный объёмом, а дальше попадаются случайные перенесённые места.

Это не демо сюжета: людей, предметов, боя и сохранений пока нет. Сцена проверяет камеру, движение, срезы, бесконечную подгрузку мира и общий стиль.

## Запуск на Mac

1. Скачай **Godot 4.7** (обычную версию, не .NET) с [godotengine.org/download/macos](https://godotengine.org/download/macos/) и перетащи `Godot.app` в «Программы». Или: `brew install --cask godot`.
2. Открой Godot → **Импорт** → выбери файл `game/project.godot` из этого репозитория → **Импортировать и редактировать**. Первый импорт займёт несколько секунд.
3. Нажми **▶ (Запустить проект)** справа вверху или **⌘B**.

Без редактора, из терминала в корне репозитория:

```sh
/Applications/Godot.app/Contents/MacOS/Godot --path game
```

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD / стрелки | Идти (относительно экрана) |
| Shift | Бежать |
| Ctrl или C | Красться |
| Пробел | Забраться на уступ (подсказка появляется, когда есть куда) |
| ПКМ (удерживать) | Смотреть на курсор |
| Колесо мыши / щипок на трекпаде | Масштаб |
| T | Сменить время суток: рассвет → день → закат → ночь |
| F2 | Пиксельный режим (×3, ×4, ×6, выкл.) |
| F3 | Отладка: координаты, сектор, число чанков, кадры в секунду |
| F1 | Скрыть подсказки |
| Esc | Пауза (на паузе Q — выход) |

Клавиши привязаны к физическим кнопкам и работают при русской раскладке.

## Что посмотреть

- **Минигольф.** Всё, что пересекло границу объёма, разрезано: дорожки, кирпичная стенка, забор, фонарь, мусорный пакет. Через пасть динозавра можно пройти насквозь.
- **Дом с магазином** — вверх по экрану от старта (на северо-запад). Объём захватил три этажа целиком, срез смотрит в камеру: видны перекрытия с арматурой, кладка, комнаты. Внутри верхние этажи скрываются. По лестнице в подъезде можно подняться на второй и третий этажи.
- **Край объёма.** Где фрагмент выше местности, виден срез земного грунта: асфальт, щебень, почва, глина. Где ниже — срез слоистой породы Кромы.
- **Реки.** Глубокая вода не пускает (плавания пока нет). Мелкие места — броды, по ним можно перейти.
- **Случайные места** примерно каждые 100–200 м: кусок дороги с машиной, дачный участок с сараем, киоск у остановки, край пшеничного поля с пугалом, гаражи. Название места появляется при входе.
- **Ночь** (T несколько раз): горят фонари минигольфа, улицы и окна дома.

## Как устроен код

Сцена собирается кодом (`scripts/main.gd`), так что её можно читать как обычную программу, без редактора.

| Папка, файл | Что делает |
| --- | --- |
| `scripts/world/world_gen.gd` | Природа Кромы: рельеф, реки, броды, влажность, размещение объёмов. Всё детерминировано от seed |
| `scripts/world/terrain_builder.gd` | Данные чанка 32 × 32 м: сетка с шагом 0,5 м, коллизия с шагом 1 м, расстановка растений |
| `scripts/world/chunk_streamer.gd` | Подгрузка чанков вокруг героя в фоновых потоках |
| `scripts/world/fragment_streamer.gd` | Строит фрагменты рядом с героем, вырезает под ними рельеф |
| `scripts/world/mats.gd` | Библиотека материалов: цвет + процедурный узор, без текстур |
| `scripts/world/scatter_meshes.gd` | Процедурные трава, папоротники, кусты, камни, деревья |
| `scripts/world/sky_rig.gd` | Солнце, освещение, время суток |
| `scripts/fragments/kit.gd` | Главный приём: содержимое ∩ цилиндр объёма через CSG; новые грани получают материал среза |
| `scripts/fragments/minigolf.gd`, `house.gd`, `random_fragments.gd` | Сами фрагменты |
| `scripts/player/` | Герой из примитивов с анимацией кодом, управление, камера 45° |
| `shaders/cut.gdshader` | Рисунок свежего среза: грунт, перекрытия, кладка |
| `shaders/common.gdshaderinc` | Общее: шум, растворение стен перед героем, скрытие верхних этажей |

Чтобы добавить новый тип места, достаточно написать функцию по образцу `RandomFragments.kiosk()` и добавить тип в `WorldGen.RANDOM_TYPES`. Срез, стенка объёма и вырез рельефа появятся сами.

## Проверки

```sh
G=/Applications/Godot.app/Contents/MacOS/Godot
$G --headless --path game --script res://tests/run_tests.gd    # мир
$G --headless --path game --script res://tests/test_house.gd   # дом
$G --headless --path game -- --frames=2000 --route=house_stairs # пройти по лестнице на 2-й этаж
```

Проверяются детерминизм мира, точное совпадение краёв соседних чанков, радиусы и непересечение объёмов, наличие рек и бродов, свободные дверные проёмы и высоты лестничных площадок. Маршрут печатает, на какой высоте герой дошёл до каждой точки.

Ещё ключи для запуска (после `--`): `--autowalk=x,z` — идти в направлении, `--autoclimb` — забираться на уступы, `--start=x,z` — стартовая точка, `--time=0..3` — время суток, `--pixel=0..3`, `--verbose`, `--tour=папка` — снять контрольные скриншоты.

## Что пока условно

- Рельеф — бесконечный шум с реками на одном уровне, как в Minecraft. Связная гидрология из `prototypes/terrain` (реки, стекающие вниз по долинам) переносится следующим шагом.
- Объёмы — вертикальные цилиндры, как решено 2 ноября. Глубина под поверхностью условно 1 м.
- Герой и все предметы — примитивы-заготовки. Стиль проверяется на них, финальные модели придут позже.
- Нет людей, фауны, предметов, сохранений, звука.
- Производительность на MacBook Air M5 ещё не замерялась: нажми F3 и посмотри кадры в секунду. Если тормозит — пиксельный режим (F2) заметно разгружает видеокарту.
