# Концепт стартовой сцены

Файл: [dinosaur-mouth-mood-v01.png](dinosaur-mouth-mood-v01.png).

Создан встроенным инструментом `image_gen` с применением навыка `imagegen`. Это растровый атмосферный концепт: он задаёт цвет, масштаб человеческого присутствия и контраст аттракциона с долиной. Это не игровая 3D-модель, не скриншот работающей игры и не доказательство производительности.

Удачные решения: тёплый свет парка, оранжевая куртка героя, холодная вода, терракотовые скалы, нелепая улыбка искусственного динозавра. Для игрового блокаута нужно точнее выдержать ортографические 45°, круг среза и доступные маршруты. Панорамная перспектива на изображении служит настроению; геометрию камеры задаёт документ 15.

Ниже сохранён полный фактически использованный промпт.
