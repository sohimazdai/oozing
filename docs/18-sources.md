# Источники по инструментам и 3D-ассетам

Проверено по официальным страницам 30–31 октября 2026 года. Это источники технических возможностей и условий использования. История, правила Кромы и игровые системы — оригинальные предложения для Oozing, а не пересказ этих материалов.

| Источник | Что использовано |
| --- | --- |
| [Godot: лицензия](https://godotengine.org/license/) | MIT и условия распространения движка в игре |
| [Godot: точность больших миров](https://godotengine.org/article/emulating-double-precision-gpu-render-large-worlds/) | Причины дрожания на больших координатах и подход с повышенной точностью |
| [Unreal Engine: лицензирование](https://www.unrealengine.com/license) | Стандартная модель лицензирования игр; для реального выпуска сверять полный действующий договор |
| [Unreal Engine: ортографическая камера](https://dev.epicgames.com/documentation/en-us/unreal-engine/orthographic-camera-in-unreal-engine) | Наличие ортографической камеры и необходимость проверки её рендеринга |
| [Unreal Engine: World Partition](https://dev.epicgames.com/documentation/en-us/unreal-engine/world-partition-in-unreal-engine) | Загрузка клеток мира; это не готовая система псевдобесконечной генерации Oozing |
| [Unreal Engine: Destruction Overview](https://dev.epicgames.com/documentation/unreal-engine/destruction-overview?lang=en-US) | Предварительное дробление, кластеры, связи в Chaos |
| [Unreal Engine: macOS](https://dev.epicgames.com/documentation/unreal-engine/macos-development-requirements-for-unreal-engine?lang=en-US) | Платформенные ограничения графических возможностей |
| [Blender: возможности](https://www.blender.org/features/) | Инструменты моделирования, анимации и подготовки контента |
| [Poly Haven: лицензия ассетов](https://polyhaven.com/license) | CC0 для опубликованных ассетов; сервис и API могут иметь отдельные правила |
| [Kenney: вопросы использования](https://kenney.nl/support) | Условия ассетов на страницах наборов и проверка приложенной лицензии |
| [Fab: Standard License](https://www.fab.com/eula) | Использование ассетов в проектах и ограничения отдельного распространения |
| [Adobe: Mixamo FAQ](https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html) | Разрешение использования в играх и ограничения автоматического риггинга |
| [Quaternius: актуальная лицензия](https://quaternius.com/license.html) | QAL v1.0 и отличие текущих условий от общего старого [FAQ](https://quaternius.com/faq.html) |

Выбор двигателя и источников ассетов в [документах14](14-asset-production.md) и [16](16-technology-and-roadmap.md) — проектная оценка, а не результат уже проведённого сравнения производительности. Никаких ассетов из перечисленных каталогов в этой сессии не приобретали и не импортировали.

Литературный импульс пользователя — ощущение проникновения чужой реальности из книг о Стрелке. Oozing не использует имена персонажей, географию, мифологию, текст или сюжетные сцены Стивена Кинга. Основной рабочий образ игры — современная хозяйственная вещь в новой природной и человеческой системе.
